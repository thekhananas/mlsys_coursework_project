\subsection*{Kernel Design and Optimizations}

\textbf{One-Block-Per-Channel Architecture:} Grid dimensions \texttt{(C,1,1)} map each block to one channel. Each block independently computes $\mu_c$ and $\sigma^2_c$ across all spatial ($H \times W$) and batch ($N$) elements, eliminating inter-block synchronization.

\textbf{Vectorized Memory Access (\texttt{float4}):} 128-bit transactions load 4 floats per memory operation, achieving optimal coalescing:
\begin{lstlisting}[language=C]
const float4* src4 = (const float4*)src;
float4 v = src4[i];  // Single 128-bit coalesced load
local_sum += v.x + v.y + v.z + v.w;
local_sq  += v.x*v.x + v.y*v.y + v.z*v.z + v.w*v.w;
\end{lstlisting}
\vspace{-0.2cm}
A cleanup loop handles remainders when $H \times W \bmod 4 \neq 0$.

\textbf{Two-Level Parallel Reduction:}
\begin{itemize}
    \item \textit{Warp-level:} \texttt{\_\_shfl\_down\_sync()} reduces within each 32-thread warp without shared memory, eliminating bank conflicts.
    \item \textit{Block-level:} Only 32 floats of shared memory store warp partial sums, which are then reduced by warp 0.
\end{itemize}

\textbf{Register-Level Accumulation:} Partial sums (\texttt{local\_sum}, \texttt{local\_sq}) accumulate in registers throughout the spatial/batch loops, avoiding shared memory traffic.

\textbf{Fused Scale-Shift Transformation:} The output normalization $y = \gamma \frac{x - \mu}{\sqrt{\sigma^2 + \varepsilon}} + \beta$ is algebraically rewritten as a single FMA: $y = \text{scale} \cdot x + \text{shift}$, where both constants are precomputed by thread 0 using \texttt{rsqrtf()} for fast reciprocal square root.

\subsection*{Kernel Design and Optimizations}

\textbf{One-Thread-Per-Output-Pixel Strategy:} Each thread computes exactly one $y[n,c,oh,ow]$, ensuring race-free execution without atomics. The 3D grid \texttt{(spatial\_blocks, C, N)} naturally maps to NCHW layout.

\textbf{Memory Coalescing via Spatial Indexing:} The $x$-dimension maps to output width ($OW$), so consecutive threads access consecutive input addresses when \texttt{stride=1}: threads read \texttt{x[...+(ow*stride+kw)]}, yielding coalesced 128B transactions.

\textbf{Implicit Zero-Padding:} Rather than allocating padded input, boundary checks (\texttt{ih $\geq$ 0 \&\& ih < H \&\& iw $\geq$ 0 \&\& iw < W}) implicitly treat out-of-bounds as zero, saving memory and avoiding copy overhead.

\textbf{Register-Based Convolution:} The $K_H \times K_W$ convolution accumulates in a register variable (\texttt{sum}), with a single global memory write per output pixel.
