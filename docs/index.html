Fuses mean/variance reduction and affine normalization into a single memory pass. Uses 1-block-per-channel grid mapping, 128-bit float4 vector loads, and register warp-shuffles (__shfl_down_sync) to collapse sums without shared-memory bank conflicts.

Depthwise 2D Convolution Kernel ↗

Direct spatial convolution mapped as one thread per output pixel across a 3D grid (spatial_blocks, C, N). Eliminates memory allocation overhead through inline coordinate boundary checks and aligns thread indexing with output width for coalesced memory reads.
