Batch Normalisation Inference Kernel ↗

Executes two passes over x (statistics reduction and affine normalisation) inside a single fused kernel launch using 1,024-thread per-channel blocks, L1/L2 cache reuse, 128-bit float4 vector loads, and register warp-shuffles (__shfl_down_sync) without shared-memory bank conflicts.

Depthwise 2D Convolution Kernel ↗

Direct spatial convolution mapped as one thread per output pixel across a 3D grid (spatial_blocks, C, N) with BLOCK_SIZE = 256. Eliminates explicit padding buffers via inline coordinate boundary checks, aligns thread indexing with output width for coalesced memory reads when stride = 1, and validates within 1e-5 of the CPU reference.
